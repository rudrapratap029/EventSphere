# EventHub - Backend Service

Phase 1 setup of the EventHub event booking platform backend.

## Tech Stack
- **Runtime:** Node.js (ES Modules)
- **Framework:** Express.js
- **Database:** MongoDB / Mongoose
- **Security:** Helmet, CORS
- **Utilities:** Morgan, Compression, Cookie-Parser, Dotenv

## Scripts
- `npm run dev`: Runs the backend server with `nodemon` for auto-reloading.
- `npm start`: Runs the backend server with Node in production mode.

## Environment Variables
Copy `.env.example` to `.env` and configure your credentials:
```bash
cp .env.example .env
```
